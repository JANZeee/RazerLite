# 0.10.0：适配证据与连接诊断

日期：2026-10-22。版本 0.10.0 / build 14。本轮完成计划中的首批软件工作，没有执行设备 Feature 查询、参数写入或新增硬件兼容性验证。以下模拟结果均不是设备实测。

## 实际变更

- 新增内置 `AdapterManifestCatalog`，包含 Viper `1532:00E6` USB、BlackWidow `1532:02D2` USB 与 macOS 蓝牙系统电量三个后端的描述。记录 VID/PID、连接规则、接口指纹、固件已知边界、功能实现、来源提交、协议测试样本位置和验证文档。没有任意报文模板、用户导入执行或动态插件加载。
- USB 适配器复用清单中的指纹：唯一匹配、USB 父节点、接口号、Usage、I/O/F 长度仍严格检查。混合设备身份或多个控制接口拒绝匹配。蓝牙保持 Razer VID 与 Bluetooth 前缀约束，不复用 USB 命令。
- 原有单一 `CapabilityState` 替换为实现状态、验证证据、当前会话三部分。实现不会因查询失败变成“未实现”；当前成功也不升级历史真机证据。键盘 RGB 与回报率查询明确为未实现，公开驱动线索保留在证据中。
- 当前结果记录来源、完成/取得时间、错误类别与简短解释，区分未读、读取中、成功、失败、接口不可用、睡眠暂停。DPI 修改另有未应用、处理中、待确认和结果未确认状态，不从一次只读成功推断设置已应用。
- 目录新增“有 USB 适配”和“目录内已发现”筛选，展示具体已实现项。上游 273 条参考不含两个新适配 PID，界面合并后为 275 项；上游目录原始列表及来源仍独立保留。蓝牙与未知 PID 的当前设备仍从侧栏查看。
- 设备信息页分别展示实现、历史证据和当前结果；详细解释与固定来源放入展开项。菜单设备子项复用同一评估的读取摘要，展开菜单不发起查询。
- 工具栏及无设备页新增“检查连接”。解释系统未发布物理 HID、接口不匹配、未读取、字段失败及观察到的其他驱动绑定。只解释已有状态；刷新只更新系统属性，不申请额外权限、不轮试接口，也不把超时判定成离线。

本地档案仍为 schema 1。没有增加自动读取、自动恢复参数、RGB 控制、回报率设置或任何新硬件写入入口。

## 诊断契约

新导出为 schema 7，应用版本 `0.10.0-capabilities-and-diagnostics`，增加：

| 字段 | 内容 |
| --- | --- |
| `adapterManifests` | 内置的审查清单；即使没有设备也可查看适配范围，不代表当前在线 |
| `adapterAssessments[deviceID]` | 当前已枚举设备的适配 ID、接口是否匹配、逐项实现/证据/会话状态与来源 |
| `connectionCheck` | 系统发现与逐设备排查建议 |

新字段均为可选解码字段，历史 schema 6 导出缺少它们仍能读取。既有原始读数和 `readSummaries` 保留。普通顶层导出不加模拟标记；模拟导出的顶层及逐设备 assessment 都明确标识来源。历史证据始终带适用范围，模拟成功不改变该等级；通用蓝牙后端不继承 `068E:00D5` 的本机系统电量记录。

JSON 时间延续 ISO 8601 秒精度，不与保留小数秒的内存 Date 做直接相等比较。系统电量的时间是应用取得时间，不是设备测量时间。没有新增序列号、蓝牙地址或输入采集。

## 界面验证

使用场景应用的真实 SwiftUI 窗口与原生控件检查：

- 目录的 USB 筛选显示两个适配项；该检查发现并修复了上游表不含新 PID 时筛选为空的问题。
- 设备信息展开能力和字段说明，显示历史记录与本次模拟来源；键盘 RGB 明确未实现，电量/充电保留模拟协议验证等级。
- 无设备页面的连接检查入口、正常状态和超时排查弹窗。
- 从连接检查打开 JSON 导出，写入 `build/ui010/native/connection-export.json`，解析确认 schema 7、模拟标识和适配清单；完成后返回连接检查。

真实窗口截图和 AX 文本位于 `build/ui010/native/`。共享能力组件另用 ImageRenderer 检查鼠标未读、键盘、蓝牙与部分失败的浅色/深色布局，产物位于 `build/ui010/`。ImageRenderer 无法正确呈现本机的原生滚动区域和按钮，因此没有把它用于连接弹窗验收；该部分采用上述真实窗口结果。

此记录不包含完整的状态栏菜单逐项点击、登录重启或跨系统 UI 验收。性能仍参考 [0.9.2 数据](PERFORMANCE092.md)，没有把本轮功能测试当作性能测量。

## 运行与复查

```sh
./scripts/test.sh
./scripts/build-app.sh release
open build/RazerLite.app

# 离线交互，全部设备服务为假服务
./scripts/build-scenarios.sh
open build/RazerLite-Scenarios.app

# 可重复渲染共享能力内容，导出模拟 JSON；完成后自动退出
open -n build/RazerLite-Scenarios.app --args --validate-capabilities-dir /absolute/existing-parent/ui010

# 被动系统枚举，不发送 Feature Report
./build/razerlite-probe > build/phase010-discovery.json
```
