# 0.11.5：菜单栏反馈与本地预设

日期：2026-11-06（Asia/Singapore），版本 0.11.5 / build 23。本轮完善现有操作，不新增设备协议、后台任务、依赖或档案格式；诊断 schema 仍为 10。

## 使用变化

- 菜单栏直接展示电量本身的读取状态及超时、权限等失败分类。其他字段成功不再遮住电量错误；历史电量继续单独标注来源、时间。失败或取消后可手动重试，未适配设备显示“电量读取尚未适配”。展开菜单不会触发读取。
- 没有连接设备时，仍可从菜单栏的“本地 DPI 档案 → 管理本地档案”打开离线预设库。
- 从菜单栏或档案库明确载入同一个预设，也会重新填入目标值；普通页面刷新不覆盖草稿。载入仍只修改编辑器，不准备或发送设备报文。设备忙碌、待确认或暂停时不可载入。
- 菜单栏载入失败会打开主窗口并显示实际错误，不再静默忽略。点击时重新检查连接及忙碌状态。
- 本地预设编辑复用现有 X/Y 联动模型，新增/编辑可见名称、整数、范围和步进提示。新建默认 1600/1600 联动；打开异轴预设保留原值并解除联动。
- 设备档案页把“已经读到 DPI”与“数值可保存”分开，非 50 步进的设备值不再提示需要重新读取。无法加载的档案保留原文件，禁用修改并持续显示错误。

## 运行与检查

```sh
./scripts/test.sh
./scripts/build-scenarios.sh
./scripts/build-app.sh release
python3 scripts/test-probe.py
```

在离线应用中检查：新建预设、联动编辑、非法名称/DPI、保存后编辑异轴值；载入到设备编辑器、修改草稿，再显式载入同一预设；检查菜单中的电量失败、历史值及无设备档案入口。离线应用使用临时档案及假服务，不接触真实外设。

## 本轮验证结果

- **215 项测试 / 41 个 suite 通过**，运行 6.502 秒，不含编译。新增 4 项测试覆盖同一预设重复载入、普通更新保留草稿、忙碌拒绝后不重放，以及陈旧请求不覆盖其他选择。现有档案存储、导入、设备生命周期与协议测试全部通过。
- Debug 离线包、Release 构建及严格 ad hoc 签名检查通过。CLI 冲突参数、无效设备目标、帮助和默认被动枚举检查通过。没有发送真实设备设置命令。
- 原生离线界面：新建默认联动；2846 双轴联动后出现步进提示且禁用保存；49 字符名称出现长度提示且禁用保存；1800/2000 保存后重新编辑仍为异轴、联动关闭。
- 从档案库载入 1800/2000 后只填入编辑器，未准备或应用设置。将 X 编辑为 2400，普通设备刷新保留草稿；从设备内档案页明确载入同一预设恢复 1800/2000。浅色编辑窗口已检查，无重叠或截断。
- 系统状态栏菜单本轮未完成原生交互验收：应用 AX 树没有暴露 MenuBarExtra，状态栏快捷键未取得入口，SystemUIServer 访问超时。菜单改动通过编译和代码审查，共用载入模型通过单元测试；不能据此声称菜单点击、菜单错误弹窗及忙碌项已真机 UI 验收。损坏档案 UI、深色和不同尺寸也未在本轮重新验证。

构建产物为 `build/RazerLite.app` 与 `build/RazerLite-Scenarios.app`。本地记录：`build/phase0115-{tests,debug,release,cli-tests}.log`、`build/ui0115/`；其中 AX 文件为完整快照，`verification.json` 是工具观察的人工摘要。原始记录不上传 GitHub。沿用的 CLT 搜索目录及 weak capture 编译警告未阻止构建；本轮没有测量 CPU、内存或启动耗时，不增加性能结论。签名检查不代表 Developer ID 或公证完成。

## 剩余边界

本轮不验证硬件设置或扩展兼容性。真实睡眠唤醒、无线外设离线及低频电量资源验收仍需完成；自动电量暂未对生产后端开放。RGB、按键映射与固件查询依然需要精确型号的协议证据。多档 DPI 与回报率设置的真机修改仍需逐次确认具体目标。
