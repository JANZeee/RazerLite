# 功能演进记录（截至 0.9.1）

以下为旧版功能说明，当前状态以 README 和各阶段验收记录为准。

侧栏和菜单栏新增“本地档案”入口，支持离线创建、搜索、重命名/编辑、复制、删除、导入和导出。当前目标仍限 Viper V4 Pro `1532:00E6` USB；手动填写的是本地目标值。连接匹配设备后可选择当前接收器并载入编辑器，实际应用继续经过独立检查与明确确认。档案保持 schema 1，增加 1 MiB 文件上限、导入预览与冲突摘要；不同内容的同标识预设作为副本保留。导入支持完整路径与文件选择入口，导出复用不覆盖同名文件的应用内 JSON 保存页。说明及验收见 [0.9.1 本地档案库](PHASE091_LOCAL_LIBRARY.md)。

没有外设时可运行 `./scripts/build-scenarios.sh`，打开 `build/RazerLite-Scenarios.app`。工作台复用正式窗口，提供 12 个固定场景、浅色/深色、紧凑尺寸、断连重连、睡眠唤醒及模拟 DPI 结果。全部设备服务均被假服务替换，档案存入独立临时目录；窗口、菜单栏和 DPI 确认页标注模拟，诊断也带模拟来源。**模拟读数不是硬件兼容性证据**，Release 不包含这些场景实现。说明及验收范围见 [0.9 离线场景](PHASE09_OFFLINE_SCENARIOS.md)。后续阶段见 [开发计划](ROADMAP.md)。

0.8.1 精简重复提示与宣传文案，整理侧栏、设置和导出页面；新增带目录入口的无设备页面、搜索无结果状态和清除按钮。协议说明保留在设备信息、悬停提示或展开项中，写入确认与“本地预览 / 试验适配”标识继续保留。设置页从应用实际信息读取版本号。当前系统深色外观下已检查无设备页、目录搜索、设置版本和导出入口；设备详情页仍待连接外设后验收。见 [界面设计说明](UI_DESIGN.md)。

已实现：Razer VID 匹配、真实 HID 属性枚举、多接口聚合、插拔通知、虚拟 HID 区分、接口详情、功能状态、菜单栏、有限日志、手动 JSON 诊断导出与只读 CLI。指定 `1532:00E6` USB 查询接口现可手动读取电量、当前 X/Y DPI 和全部 DPI 档位；查询结果带时间、部分成功和错误状态。

Viper V4 Pro 性能页新增独立“读取回报率”，本机 Debug CLI 和 Release 窗口均读回 **1000 Hz**。这是设备配置，不是实际输入报告频率测量；不发送频率设置命令。严格请求/响应、原始抓包证据及范围见 [0.6 回报率审查](PHASE06_PROTOCOL_REVIEW.md)。

0.7 在 Viper V4 Pro 总览加入独立“读取充电状态”，也可使用 CLI `--read-charging`。仅接受明确的“充电中 / 未充电”，带取得时间、失败分类，并写入 schema 5 诊断与菜单栏；不把未知值或读取失败当成未充电，也不把未充电解释为正在放电。启动、刷新与热插拔不会触发该查询。实现已通过协议和生命周期模拟测试，**本轮设备未连接，尚未完成此功能的本机硬件验证**。原始抓包、型号边界及验证步骤见 [0.7 充电状态审查](PHASE07_CHARGING_READ.md)。

0.8 为 BlackWidow V4 Low-profile TKL HyperSpeed `1532:02D2` USB 接收器增加独立试验适配：严格匹配已审查的 interface 2 / Usage `01/02` / Input 8、Output 0、Feature 90 字节，并使用该型号公开补丁中的事务 `9F`。总览可分别“试读电池电量”和“试读充电状态”，菜单栏展示已取得的值；诊断更新到 schema 6。两项互不依赖，0% 电量有效，失败不会变成默认电量。**102 项测试与 Release 构建已通过；尚未完成 macOS 真机查询和原生界面交互验收**。不切换模式、不订阅输入、不修改设备；不自动扩大到 `02D4`、其他键盘或蓝牙。依据和运行步骤见 [0.8 键盘适配说明](PHASE08_KEYBOARD_POWER.md)。

发现层面向所有 macOS 可见的 Razer HID，并不限制为两款实测设备。内置 273 条型号/PID 参考与可搜索“Razer 设备目录”，未知 PID 也正常显示系统基本信息；目录不表示私有状态协议已支持。参考 FerrisPulse 的审查、PID 冲突及后续多设备适配边界见 [多设备读取说明](FERRISPULSE_REVIEW.md)。

发现同时匹配 USB VID `1532` 和蓝牙侧 `068E`；后者仅接受 Bluetooth / Bluetooth Low Energy transport，防止混淆 USB 标识。已在本机发现 `BSK MOBILE`（BLE，`068E:00D5`），无需输入监控权限。现可点击“读取系统电量”取得 macOS 发布的电量，本机 CLI 与 Release 窗口已读到 100%。优先读取同一 HID 节点属性，缺失时按需运行一次有时限的系统蓝牙快照，以地址和 VID/PID 精确关联；不按名称猜测，不保存地址或原始快照。界面与菜单栏显示系统缓存及应用取得时间，不自动轮询。其蓝牙 DPI/RGB 私有协议及标准 GATT 电量仍未适配。详见 [系统电量读取](SYSTEM_BATTERY.md)。

界面采用 macOS 原生窗口与侧栏，配合石墨灰、雷蛇绿及圆角面板，跟随系统浅色/深色外观。设备总览、鼠标性能、键盘灯光预览、按键页和设备信息已分开。键盘“灯光”页可在本地选择颜色和拖动亮度；这些数值仅表示窗口中的预览，**不会读取或写入设备灯光**。详情见 [界面设计说明](UI_DESIGN.md)。

DPI 设置已实现检查变更、逐次确认、整表提交和读回流程，**已在用户明确授权后完成第 3 档 2846/2846 → 2800/2800 的真机写入与独立读回验证**。此命令可能保存到设备，不能保证临时生效，详见 [DPI 变更说明](DPI_WRITE.md)。

Viper V4 Pro 的“档案”页现可把经过手动读取的当前 X/Y DPI 保存为本地 JSON 预设，支持导入、导出、删除和菜单栏选择。选择预设只把 X/Y 目标填入性能编辑器，**不会**读取、写入或自动恢复设备；真正改动仍要经过“检查变更… → 确认写入设备 → 完整读回”。档案只匹配已审查的 `1532:00E6` USB 适配器的 VID/PID/连接方式，不保存 IORegistry 会话 ID、USB 父节点、序列号或写入许可；因此同型号多接收器共享型号级选择。说明见 [本地 DPI 档案](LOCAL_PROFILES.md)。

尚未实现回报率设置、设备 RGB、固件查询、按键映射、宏、板载配置或自动加载；键盘灯光仍为本地预览，新增电源状态为试验读取。界面逐项标明状态。成功读取某个值后，该连接的对应能力才标为已实现；“待验证”不表示当前连接已可用。读取摘要区分接口已发现、设备曾响应、系统缓存已取得、部分成功与未确认；超时不会被直接叫作离线或休眠。

默认启动、刷新及热插拔只读取系统属性。点击鼠标页右上角“读取状态”或显式运行 CLI `--read-mouse` 才打开已匹配的非输入查询接口，发送两个已审查的查询请求并接收响应。这里的只读查询使用 SET_REPORT + GET_REPORT，不包含参数设置命令。新增 DPI 设置仅由“检查变更”之后的独立确认页触发；取消不设置设备。不会独占设备、捕获键鼠输入、停止官方软件或自动轮询。具体协议与真机验证见 [只读查询说明](READ_ONLY_PROTOCOL.md)。
